# 国金 PTrade API 文档版本说明

本目录中的原始 API 文档文件已作为 LightQuant 项目资料保存。技能包引用它们作为特定版本的接口参考。

## 文档来源与版本

- 部署/券商文档：国金版本 PTrade。
- `ptradeapi.html` 的“接口版本变动”记录中，最高列出的接口变更版本为 `PTrade1.0-QTV202401.05.032`。
- 该文档区分 Python 3.5 与 Python 3.11 运行环境，部分 API 返回类型和依赖包不同。
- 此版本号是该份文档所列的 API 变更版本，不代表已确认某个账户当前安装的客户端/服务端版本。
- `财务数据api.html` 未见独立的软件/API 版本标记。

使用者应向自己券商确认实际 PTrade 客户端/接口版本、Python 运行环境和可用权限。回测、模拟和实盘也可能存在差异；不要仅凭本文档声明当前环境兼容。
