# 安全与输出规则

## 范围

支持聚宽与 PTrade 策略代码的生成、修改、转换、解释和平台问题调试。不提供投资建议、收益保证、证券推荐或脱离实现代码的市场预测。用户给定证券代码可以作为策略输入或示例，不得包装为推荐。

## 输出

- 保持用户策略意图，除非用户明确要求更改行为。
- 说明平台限制、未知 API 能力和转换近似。
- 将回测风险限定在数据质量、撮合/执行假设、平台差异和策略实现上。
- 交付便于审阅和验证的代码；不要把静态检查说成回测验证。
- 解读策略时说明运行流程、参数、交易逻辑、风控和平台依赖。

## 编码

- 修改含中文的策略文件前识别实际编码并保留可读注释/日志。
- 新建文件优先使用 UTF-8，除非目标平台或用户明确要求其他编码。
- 不把乱码当作无关显示问题，也不以乱码注释作为结论证据。

## 反馈归因

用户反馈结果不符合预期时，先归类为平台 API/环境差异、转换语义偏差、数据口径问题、策略解读不清、格式问题或缺失平台参考，再修改负责该问题的最小范围。
