# 聚宽（JoinQuant）平台参考

本文件是策略开发和转换的工作提示，不替代聚宽平台当前文档。聚宽提供的接口和可用数据会随运行模块及平台能力变化；以用户账号当前可访问的 API 文档和实际运行环境为准。

## 查阅范围

仅在策略实际用到时查对应文档章节：

- 初始化、盘前/盘中/盘后回调、定时任务和调度时间语义
- `context`、`g`、组合、账户、现金和持仓对象
- 行情、历史序列、当前数据、暂停/涨跌停状态、指数成分和证券列表
- 财务查询、估值、因子、额外数据与基金净值
- 下单、目标金额/数量、撤单、订单状态及成交回报
- 日志、交易成本、滑点、回测和模拟环境限制

## 兼容性和运行规则

- 仅按目标运行模块确认 API；研究、回测、模拟和交易可用能力可能不同。
- 读取 `get_price`、`history`、`attribute_history`、`get_fundamentals` 等结果前检查 `None`、空对象、缺列、历史长度和价格有效性。
- 区分“函数被定义”和“函数进入正式调度/调用路径”。
- 新增 `g.*` 状态在初始化中创建，明确日计数、缓存、买入记录和连续信号确认值的重置时机。
- 不乐观更新交易状态。核对订单返回值；订单拒绝或没有成功证据时，保持原状态并说明。
- 在全部下单路径中检查暂停状态、无效价格、涨跌停方向、现金、可卖数量、最小交易单位和目标数量是否变化。
- 财务数据筛选需使用当时已经可得的信息，确认报告期与公告/可用日期口径，避免使用未来披露数据。
- 旧示例可能含 Python 2 写法、已弃用 pandas `.ix` 或不再支持的接口。不要假设旧接口仍然可用；以当前平台文档确认。
- 对软性交易限制可记录跳过原因，避免改写用户策略来消除平台提示。
